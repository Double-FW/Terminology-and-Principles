## Principal implementation questions

| Issue | Proposed treatment |
| --- | --- |
| Name | LGIR as the primary framework name; Agentic POUR as an analogy. |
| A/AA labels | Explicitly local and provisional, with no WCAG or agentic conformance claim. |
| Stop and undo | Distinguish cancellation request, confirmed stop, rollback, compensation and irreversible effects. |
| Transparency | Explain evidence, decision factors and actual outcomes without exposing protected data or promising hidden internal reasoning. |
| Confidence | Separate source reliability, retrieval relevance, model uncertainty and action risk. |
| Model changes | Evaluate supported versions and scenarios; an open schema does not guarantee unchanged behaviour. |
| Accessible co-agency | Support authorised intervention without excessive interruptions or compulsory simultaneous output channels. |

These are editorial proposals; they do not silently change Gareth's definition.
